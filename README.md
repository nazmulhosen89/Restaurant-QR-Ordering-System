# NeXt-Restro-Automation
A fully AI powered multi-restaurant automation solution with QR ordering, table management, KOT, billing, inventory, requisitions, recipes, POS, reports, and subscriptions.

## Features

- QR Ordering
- Table Management
- Order Management
- Kitchen Orders (KOT)
- Billing / Invoice
- Inventory Management
- Staff Requisitions
- Wastage Management
- Low Stock Alerts
- Stock Ledger
- Recipe Management
- POS
- Multi Restaurant Support

## Installation

Upload plugin and activate.
